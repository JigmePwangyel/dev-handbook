Cheat Sheets

Dense, scannable reference tables for the commands you will use daily. Bookmark this page; the goal is recall speed, not explanation. Each section links back to a lesson for the why.

Handy one-liners

# what is eating my disk?
du -xh / 2>/dev/null | sort -rh | head -20
# what is using port 3000?
sudo lsof -i :3000
# top client IPs in nginx
awk '{print $1}' /var/log/nginx/access.log | sort | uniq -c | sort -nr | head
# requests per status code
awk '{print $9}' /var/log/nginx/access.log | sort | uniq -c | sort -nr
# watch a command every 2s
watch -n2 'docker ps --format "table {{.Names}}\t{{.Status}}"'
# generate a strong random secret
openssl rand -base64 32
# quick file server
python3 -m http.server 8000
# test a webhook locally with a throwaway payload
curl -X POST -H 'content-type: application/json' -d '{"ping":true}' localhost:3000/hook
