Glossary A to Z

Terms you will meet across this handbook, in plain language. Skim it now, return when a word trips you up.

TermMeaning
A recordDNS record mapping a hostname to an IPv4 address (AAAA for IPv6).
AnsibleAgentless configuration-management tool that applies YAML "playbooks" over SSH.
API gatewaySingle entry point that routes, authenticates and rate-limits calls to backend services.
ArtifactThe build output you deploy: a binary, JAR, zip, or container image.
AutoscalingAutomatically adding or removing instances based on load.
Availability zone (AZ)An isolated data centre (or group) within a cloud region; spread across AZs for resilience.
BackupA copy of data that lets you restore after loss. Untested backups are hopes, not backups.
Bastion hostHardened server used as the single SSH entry point into a private network.
Blue-green deploymentRun old (blue) and new (green) versions side by side, then switch traffic at once.
BranchIndependent line of development in Git.
BuildCompiling/bundling source into a deployable artifact.
CacheFast storage of previously computed results (Redis, CDN, browser).
Canary releaseSend a small share of traffic to the new version first, watch, then expand.
CDNContent Delivery Network: edge servers caching content near users.
CI (continuous integration)Merging often and automatically building and testing every change.
CD (delivery / deployment)Delivery: every change is releasable. Deployment: every passing change is released automatically.
CIDRNotation for IP ranges, e.g. 10.0.0.0/16.
ClusterA group of machines managed together (e.g. a Kubernetes cluster).
CNAMEDNS alias pointing one name to another name.
Config managementKeeping servers in a declared state (Ansible, Puppet, Chef).
ContainerIsolated process with its own filesystem view, sharing the host kernel.
CronUnix scheduler that runs commands at set times.
DaemonBackground process, usually a service.
DeploymentReleasing a version to an environment; also a Kubernetes object managing replicas.
DevSecOpsIntegrating security checks throughout the pipeline.
Disaster recovery (DR)Plan and capability to restore service after a major failure.
DNSDomain Name System: translates names to IP addresses.
DockerTooling for building and running containers.
DockerfileRecipe describing how to build a container image.
DORA metricsFour delivery metrics: deploy frequency, lead time, change failure rate, recovery time.
Egress / ingressTraffic leaving / entering a network. In Kubernetes, Ingress routes external HTTP to services.
EnvironmentAn isolated deployment of the system (dev, staging, production).
Environment variableNamed value passed to a process, used for configuration.
Error budgetAllowed unreliability implied by an SLO (100% minus SLO).
FirewallRules that allow or block network traffic (ufw, security groups).
Feature flagRuntime switch that enables code paths without redeploying.
GitOpsGit is the source of truth for desired state; an agent applies it (Argo CD, Flux).
Health checkEndpoint or probe that tells a load balancer or orchestrator whether an instance is OK.
HelmPackage manager for Kubernetes manifests (charts).
Horizontal scalingAdding more instances (vs vertical: a bigger instance).
HTTP / HTTPSWeb protocol; HTTPS adds TLS encryption.
IaaS / PaaS / SaaSRent infrastructure / a platform to run apps / finished software.
IaCInfrastructure as Code: defining infrastructure in version-controlled files.
IAMIdentity and Access Management: who can do what in a cloud account.
IdempotentRunning an operation many times yields the same result as once. Essential for automation.
ImageImmutable template from which containers (or VMs) are started.
Immutable infrastructureReplace servers with new versions instead of modifying them in place.
IncidentAn event degrading service that needs response.
Ingress controllerComponent implementing Kubernetes Ingress rules (nginx, Traefik).
JWTJSON Web Token: signed token carrying identity claims.
Kubernetes (K8s)Orchestrator that schedules and heals containers across machines.
LatencyTime for a request to complete.
Load balancerDistributes traffic across backends.
LogTimestamped record of events emitted by software.
MetricNumeric measurement over time (CPU, requests/sec).
MicroservicesArchitecture of small, independently deployable services.
Migration (database)Versioned change to a database schema.
Monitoring / observabilityCollecting signals (logs, metrics, traces) to understand system behaviour.
NamespaceLogical partition (Kubernetes namespaces; Linux kernel namespaces for containers).
nginxPopular web server and reverse proxy.
On-callRotation of people who respond to alerts.
OrchestrationAutomated placement, scaling and healing of workloads.
PipelineAutomated sequence of stages (build, test, deploy).
PodSmallest Kubernetes unit: one or more containers sharing network and storage.
PortNumber identifying a service on a host (22 SSH, 80 HTTP, 443 HTTPS).
PostmortemBlameless write-up of an incident and follow-up actions.
ProvisioningCreating infrastructure (servers, networks, databases).
Pull request (PR/MR)Proposal to merge a branch, reviewed and checked by CI.
RegistryStorage for container images or packages (Docker Hub, GHCR, ECR).
ReplicaOne of several identical copies of a workload.
Reverse proxyServer in front of apps that forwards client requests to them.
RollbackReturning to a previous known-good version.
Rolling updateReplace instances gradually so service stays up.
RunbookStep-by-step guide for an operational task or alert.
SecretSensitive value (password, key, token) that must be stored and rotated carefully.
Security groupCloud-level virtual firewall attached to instances.
Service meshInfrastructure layer handling service-to-service traffic, mTLS and telemetry (Istio, Linkerd).
SLA / SLO / SLIContractual promise / internal target / the measurement.
SRESite Reliability Engineering: operations approached with software engineering.
SSHSecure Shell: encrypted remote login and tunnelling.
StatelessKeeps no per-client data between requests; easy to scale.
SystemdLinux init system and service manager.
TerraformDeclarative IaC tool for provisioning cloud resources (OpenTofu is the open fork).
ThroughputWork completed per unit time.
TLSTransport Layer Security: encryption and identity for connections.
ToilManual, repetitive operational work that could be automated.
TraceRecord of one request's path through multiple services.
TTLTime to live: how long a DNS answer or cache entry stays valid.
VPCVirtual Private Cloud: your private network in a cloud provider.
VPSVirtual Private Server: a rented virtual machine.
VolumePersistent storage attached to a container or VM.
WebhookHTTP callback one system sends to another when an event happens.
YAMLIndentation-based data format used by CI, Kubernetes and Ansible.
Zero downtimeDeploying without users seeing errors or outages.
Acronym habit

When you meet a new acronym, expand it once in your notes. Most DevOps jargon is a simple idea with an intimidating name.
