Building an HTTP API

Go's standard library is production-grade for web services. Since Go 1.22 the built-in router supports methods and path parameters, so you can build a clean REST API with zero dependencies.

Hello, server

package main

import (
    "fmt"
    "log"
    "net/http"
)

func main() {
    mux := http.NewServeMux()
    mux.HandleFunc("GET /health", func(w http.ResponseWriter, r *http.Request) {
        fmt.Fprintln(w, "ok")
    })
    log.Fatal(http.ListenAndServe(":8080", mux))
}

A small todo API

type Todo struct {
    ID    int    `json:"id"`
    Title string `json:"title"`
    Done  bool   `json:"done"`
}

type Server struct {
    mu     sync.Mutex
    todos  map[int]Todo
    nextID int
}

func writeJSON(w http.ResponseWriter, status int, v any) {
    w.Header().Set("Content-Type", "application/json")
    w.WriteHeader(status)
    json.NewEncoder(w).Encode(v)
}

func (s *Server) list(w http.ResponseWriter, r *http.Request) {
    s.mu.Lock(); defer s.mu.Unlock()
    out := make([]Todo, 0, len(s.todos))
    for _, t := range s.todos { out = append(out, t) }
    writeJSON(w, http.StatusOK, out)
}

func (s *Server) create(w http.ResponseWriter, r *http.Request) {
    var in struct{ Title string `json:"title"` }
    if err := json.NewDecoder(r.Body).Decode(&in); err != nil || in.Title == "" {
        writeJSON(w, http.StatusBadRequest, map[string]string{"error": "title required"})
        return
    }
    s.mu.Lock(); defer s.mu.Unlock()
    s.nextID++
    t := Todo{ID: s.nextID, Title: in.Title}
    s.todos[t.ID] = t
    writeJSON(w, http.StatusCreated, t)
}

func (s *Server) get(w http.ResponseWriter, r *http.Request) {
    id, err := strconv.Atoi(r.PathValue("id"))   // path parameter
    if err != nil {
        writeJSON(w, 400, map[string]string{"error": "bad id"}); return
    }
    s.mu.Lock(); defer s.mu.Unlock()
    t, ok := s.todos[id]
    if !ok {
        writeJSON(w, 404, map[string]string{"error": "not found"}); return
    }
    writeJSON(w, 200, t)
}

func main() {
    s := &Server{todos: map[int]Todo{}}
    mux := http.NewServeMux()
    mux.HandleFunc("GET /todos", s.list)
    mux.HandleFunc("POST /todos", s.create)
    mux.HandleFunc("GET /todos/{id}", s.get)
    log.Fatal(http.ListenAndServe(":8080", mux))
}

Middleware

Middleware is just a function that wraps an http.Handler:

func logging(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        start := time.Now()
        next.ServeHTTP(w, r)
        log.Printf("%s %s %v", r.Method, r.URL.Path, time.Since(start))
    })
}

http.ListenAndServe(":8080", logging(mux))

Production-ready server settings

srv := &http.Server{
    Addr:              ":8080",
    Handler:           logging(mux),
    ReadHeaderTimeout: 5 * time.Second,
    ReadTimeout:       10 * time.Second,
    WriteTimeout:      15 * time.Second,
    IdleTimeout:       60 * time.Second,
}
Never use bare ListenAndServe in production

The defaults have no timeouts, so slow or malicious clients can hold connections open forever. Use an explicit http.Server with timeouts, and pair it with graceful shutdown (see the context lesson).

Databases and frameworks

  • Database: database/sql with a driver like pgx, or sqlc to generate type-safe code from SQL.
  • Routers/frameworks (optional): chi, Gin, Echo, Fiber. The stdlib mux is often enough now.
  • Structured logging: the standard log/slog package.
