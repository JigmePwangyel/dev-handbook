JSON, Files and I/O

Most real programs read configuration, write files and speak JSON. The standard library handles all of it with encoding/json, os, io and bufio.

Encoding JSON

type Product struct {
    ID       int      `json:"id"`
    Name     string   `json:"name"`
    Price    float64  `json:"price"`
    Tags     []string `json:"tags,omitempty"`   // omitted when empty
    internal string                              // unexported: ignored
}

p := Product{ID: 1, Name: "Mug", Price: 9.5}
data, err := json.Marshal(p)
fmt.Println(string(data))        // {"id":1,"name":"Mug","price":9.5}

pretty, _ := json.MarshalIndent(p, "", "  ")

Decoding JSON

var p Product
err := json.Unmarshal([]byte(`{"id":2,"name":"Pen","price":1.2}`), &p)

// unknown shape? decode into a map
var m map[string]any
json.Unmarshal(data, &m)
fmt.Println(m["name"])           // numbers decode as float64!

Fields must be exported (capitalized) to be encoded or decoded.

Streaming with Encoder/Decoder

json.NewEncoder(os.Stdout).Encode(p)

dec := json.NewDecoder(r.Body)
dec.DisallowUnknownFields()      // strict: reject unexpected keys
if err := dec.Decode(&p); err != nil { /* 400 Bad Request */ }

Custom marshaling

type Status int
const (Active Status = iota; Disabled)

func (s Status) MarshalJSON() ([]byte, error) {
    return json.Marshal([...]string{"active", "disabled"}[s])
}

Files

// small files: read or write in one call
data, err := os.ReadFile("config.json")
err = os.WriteFile("out.txt", []byte("hello\n"), 0o644)

// line by line (large files)
f, err := os.Open("big.log")
if err != nil { return err }
defer f.Close()

sc := bufio.NewScanner(f)
for sc.Scan() {
    line := sc.Text()
    fmt.Println(line)
}
if err := sc.Err(); err != nil { return err }

// create or append
out, err := os.OpenFile("app.log", os.O_APPEND|os.O_CREATE|os.O_WRONLY, 0o644)

Embedding files in the binary

import "embed"

//go:embed templates/*.html
var templates embed.FS

Ship static assets inside your single binary, which is handy for Docker and for CLIs.
