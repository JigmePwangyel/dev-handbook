Channels

A channel is a typed conduit through which goroutines send and receive values. It both transfers data and synchronizes the two sides.

Basics

ch := make(chan int)      // unbuffered channel of ints

go func() {
    ch <- 42               // send (blocks until someone receives)
}()

v := <-ch                  // receive (blocks until someone sends)
fmt.Println(v)

Unbuffered vs buffered

unbuf := make(chan int)       // send and receive rendezvous
buf   := make(chan int, 3)    // holds up to 3 values

buf <- 1; buf <- 2; buf <- 3   // fine, no receiver needed
// buf <- 4                   // would block: buffer full
fmt.Println(len(buf), cap(buf))   // 3 3

Closing and ranging

func produce(n int) <-chan int {
    out := make(chan int)
    go func() {
        defer close(out)            // sender closes, signalling "no more"
        for i := 0; i < n; i++ { out <- i }
    }()
    return out
}

for v := range produce(5) {         // loops until closed
    fmt.Println(v)
}

v, ok := <-ch                       // ok == false when closed and drained
  • Only the sender should close a channel, and only once.
  • Sending on a closed channel panics. Receiving from one returns the zero value immediately.
  • You do not have to close channels for garbage collection. Close only to signal completion.

Directional channels

func producer(out chan<- int) { out <- 1 }   // send-only
func consumer(in <-chan int)  { <-in }        // receive-only

Directions make APIs self-documenting and let the compiler catch misuse.

Worker pool

func worker(id int, jobs <-chan int, results chan<- int) {
    for j := range jobs {
        results <- j * j
    }
}

func main() {
    jobs := make(chan int, 100)
    results := make(chan int, 100)

    var wg sync.WaitGroup
    for w := 1; w <= 4; w++ {
        wg.Add(1)
        go func() { defer wg.Done(); worker(w, jobs, results) }()
    }

    for i := 1; i <= 20; i++ { jobs <- i }
    close(jobs)

    go func() { wg.Wait(); close(results) }()
    for r := range results { fmt.Println(r) }
}

Deadlocks

ch := make(chan int)
ch <- 1        // fatal error: all goroutines are asleep - deadlock!

If every goroutine is blocked, the runtime detects it and crashes. A nil channel blocks forever on both send and receive. That is occasionally useful inside select.
