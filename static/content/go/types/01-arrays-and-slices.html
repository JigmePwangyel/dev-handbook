Arrays and Slices

Arrays have a fixed size and are rarely used directly. Slices are the workhorse: a flexible, dynamically sized view over an underlying array. Understanding how slices really work prevents the most common Go bugs.

Arrays

var a [3]int            // [0 0 0]
b := [3]string{"x", "y", "z"}
c := [...]int{1, 2, 3, 4}   // compiler counts: [4]int

The length is part of the type: [3]int and [4]int are different types. Arrays are copied on assignment.

Slices

s := []int{1, 2, 3}        // slice literal
s = append(s, 4, 5)        // grows as needed
fmt.Println(len(s), cap(s))

t := make([]int, 3)        // len 3, cap 3, zeros
u := make([]int, 0, 100)   // len 0, cap 100: preallocate

sub := s[1:3]              // elements 1 and 2 (end exclusive)
first2 := s[:2]
rest := s[2:]
copy(dst, src)             // copy elements between slices

What a slice really is

 slice header (3 words)              underlying array
 ┌─────────┬─────┬─────┐            ┌───┬───┬───┬───┬───┐
 │ pointer │ len │ cap │ ─────────▶ │ 1 │ 2 │ 3 │ 4 │ 5 │
 └─────────┴─────┴─────┘            └───┴───┴───┴───┴───┘

A slice is a small struct: pointer to an array, a length and a capacity. Slicing creates a new header over the same array:

a := []int{1, 2, 3, 4, 5}
b := a[1:3]
b[0] = 99
fmt.Println(a)  // [1 99 3 4 5]  — shared memory!

append and capacity

append reuses the array if capacity allows; otherwise it allocates a bigger one and copies. Always assign the result:

s = append(s, x)        // correct
append(s, x)            // compile error: result unused

// gotcha: two slices may or may not share memory after append
a := make([]int, 3, 10)
b := append(a, 1)
c := append(a, 2)       // overwrites b's last element!
fmt.Println(b[3], c[3]) // 2 2
Aliasing gotcha

If you need an independent copy, make one: clone := slices.Clone(s) (package slices, Go 1.21+) or append([]int(nil), s...).

nil vs empty

var s []int          // nil, len 0
t := []int{}         // empty, non-nil, len 0
fmt.Println(s == nil, t == nil) // true false
// both work fine with len, range and append

Useful helpers: the slices package

import "slices"

slices.Sort(xs)
slices.Contains(xs, 3)
i, found := slices.BinarySearch(xs, 3)
slices.Reverse(xs)
slices.Max(xs)
xs = slices.Delete(xs, 1, 3) // remove xs[1:3]
