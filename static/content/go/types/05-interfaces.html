Interfaces

Interfaces are Go's mechanism for abstraction and polymorphism. They are satisfied implicitly: a type implements an interface simply by having the right methods. No implements keyword.

Defining and using

type Shape interface {
    Area() float64
    Perimeter() float64
}

type Rect struct{ W, H float64 }
type Circle struct{ R float64 }

func (r Rect) Area() float64        { return r.W * r.H }
func (r Rect) Perimeter() float64   { return 2 * (r.W + r.H) }
func (c Circle) Area() float64      { return math.Pi * c.R * c.R }
func (c Circle) Perimeter() float64 { return 2 * math.Pi * c.R }

func describe(s Shape) {
    fmt.Printf("area=%.2f perimeter=%.2f\n", s.Area(), s.Perimeter())
}

describe(Rect{3, 4})
describe(Circle{5})   // both satisfy Shape without declaring it

Small interfaces are best

The standard library's most powerful interfaces have one method:

type Reader interface { Read(p []byte) (n int, err error) }
type Writer interface { Write(p []byte) (n int, err error) }
type Stringer interface { String() string }
type error interface { Error() string }

Because io.Reader is so small, files, network connections, HTTP bodies, gzip streams and in-memory buffers are all interchangeable.

func countBytes(r io.Reader) (int64, error) {
    return io.Copy(io.Discard, r)
}
countBytes(strings.NewReader("hello"))
countBytes(os.Stdin)
"Accept interfaces, return structs"

Define small interfaces where they are consumed, not where the type is defined. Functions accept the narrowest interface they need and return concrete types.

The empty interface and any

var x any = 42       // any == interface{}: holds a value of any type
x = "hello"

Type assertions and type switches

var v any = "hi"
s, ok := v.(string)      // safe: ok is false on mismatch
n := v.(int)             // panics if v is not an int!

switch t := v.(type) {
case string: fmt.Println("string of length", len(t))
case int:    fmt.Println("int", t)
case nil:    fmt.Println("nil")
default:     fmt.Printf("other: %T\n", t)
}

Composing interfaces

type ReadWriter interface {
    Reader
    Writer
}

The nil interface gotcha

func find() error {
    var e *MyError = nil
    return e            // non-nil interface holding a nil pointer!
}
fmt.Println(find() == nil)  // false

An interface value is a (type, value) pair. It is nil only if both are nil. Return a literal nil for "no error".
