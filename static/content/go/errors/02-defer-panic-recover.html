defer, panic and recover

defer guarantees cleanup. panic is for unrecoverable bugs, not ordinary errors. recover lets you stop a panic at a boundary, such as an HTTP handler.

defer in depth

func process(path string) error {
    f, err := os.Open(path)
    if err != nil { return err }
    defer f.Close()                 // runs when process returns

    mu.Lock()
    defer mu.Unlock()               // pair lock/unlock together

    // ...
    return nil
}

Multiple defers run in LIFO order:

for i := 0; i < 3; i++ {
    defer fmt.Println(i)
}
// prints 2, 1, 0
Defer in loops

Defers run at function exit, not loop-iteration exit. Opening thousands of files in a loop with defer f.Close() leaks until the function returns. Extract the loop body into its own function.

Modifying named results

func readAll(path string) (data []byte, err error) {
    f, err := os.Open(path)
    if err != nil { return nil, err }
    defer func() {
        if cerr := f.Close(); err == nil { err = cerr }  // surface close error
    }()
    return io.ReadAll(f)
}

panic

A panic stops normal execution, runs deferred functions while unwinding the stack, then crashes the program with a stack trace.

var m map[string]int
m["a"] = 1                 // panic: assignment to entry in nil map

s := []int{1, 2, 3}
_ = s[5]                   // panic: index out of range

panic("this should never happen")

Use panic only for programmer errors (impossible states, failed invariants) or during startup (e.g. regexp.MustCompile of a bad constant pattern). Expected failures should be errors.

recover

recover works only inside a deferred function and returns the panic value:

func safe(fn func()) (err error) {
    defer func() {
        if r := recover(); r != nil {
            err = fmt.Errorf("recovered: %v", r)
        }
    }()
    fn()
    return nil
}

err := safe(func() { var m map[string]int; m["x"] = 1 })
fmt.Println(err)   // recovered: assignment to entry in nil map

Real-world use: middleware

func recoverMiddleware(next http.Handler) http.Handler {
    return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        defer func() {
            if rec := recover(); rec != nil {
                log.Printf("panic: %v\n%s", rec, debug.Stack())
                http.Error(w, "internal error", 500)
            }
        }()
        next.ServeHTTP(w, r)
    })
}

(The net/http server already recovers per-request panics, but custom middleware lets you log and respond your way.)
