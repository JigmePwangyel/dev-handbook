Testing

Testing is built into the language and toolchain: no framework required. Test files end in _test.go, test functions start with Test, and go test runs them.

Your first test

// calc.go
package calc
func Add(a, b int) int { return a + b }
// calc_test.go
package calc

import "testing"

func TestAdd(t *testing.T) {
    got := Add(2, 3)
    want := 5
    if got != want {
        t.Errorf("Add(2,3) = %d; want %d", got, want)
    }
}
go test ./...            # all packages
go test -v               # verbose
go test -run TestAdd     # filter by regex
go test -cover           # coverage summary
go test -race ./...      # data race detector (use it in CI!)

t.Errorf marks failure and continues; t.Fatalf stops the test immediately.

Table-driven tests (the Go idiom)

func TestDivide(t *testing.T) {
    tests := []struct {
        name    string
        a, b    float64
        want    float64
        wantErr bool
    }{
        {"normal", 10, 2, 5, false},
        {"negative", -9, 3, -3, false},
        {"by zero", 1, 0, 0, true},
    }
    for _, tc := range tests {
        t.Run(tc.name, func(t *testing.T) {
            got, err := Divide(tc.a, tc.b)
            if (err != nil) != tc.wantErr {
                t.Fatalf("err = %v, wantErr %v", err, tc.wantErr)
            }
            if got != tc.want {
                t.Errorf("got %v, want %v", got, tc.want)
            }
        })
    }
}

Each row becomes a named subtest, so failures point to the exact case, and adding a case is one line.

Helpers and setup

func newTestServer(t *testing.T) *Server {
    t.Helper()                      // report failures at the caller's line
    dir := t.TempDir()              // auto-cleaned temp directory
    t.Cleanup(func() { /* teardown */ })
    return NewServer(dir)
}

func TestHealth(t *testing.T) {
    req := httptest.NewRequest("GET", "/health", nil)

    healthHandler(rec, req)

Benchmarks and fuzzing

func BenchmarkAdd(b *testing.B) {
    for i := 0; i < b.N; i++ { Add(1, 2) }
}
// go test -bench=. -benchmem

func FuzzParse(f *testing.F) {
    f.Add("42")
    f.Fuzz(func(t *testing.T, s string) { Parse(s) })  // must not panic
}
// go test -fuzz=FuzzParse

Testing with interfaces (fakes)

type Store interface { Get(id int) (*User, error) }

type fakeStore struct{ users map[int]*User }
func (f fakeStore) Get(id int) (*User, error) {
    if u, ok := f.users[id]; ok { return u, nil }
    return nil, ErrNotFound
}

// the service depends on the interface, so tests inject the fake
svc := NewService(fakeStore{users: map[int]*User{1: {Name: "Ada"}}})
Keep it simple

The standard testing package is enough for most projects. Optional helpers like testify or go-cmp are popular but never required.

Try it

  1. Write a table-driven test for a function IsPalindrome(string) bool, including empty strings and mixed case.
  2. Run with -cover and open the HTML report: go test -coverprofile=c.out && go tool cover -html=c.out.
