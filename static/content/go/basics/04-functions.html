Functions

Functions are first-class values in Go. They can return multiple values, be passed around, and close over variables. Multiple returns are the foundation of Go's error handling.

Basics

func add(a, b int) int {
    return a + b
}

func greet(name string) {
    fmt.Println("Hello,", name)
}

Multiple return values

func divide(a, b float64) (float64, error) {
    if b == 0 {
        return 0, errors.New("division by zero")
    }
    return a / b, nil
}

result, err := divide(10, 2)
if err != nil { log.Fatal(err) }

_, err = divide(1, 0)   // _ discards a value you don't need

Named returns

func minMax(xs []int) (min, max int) {
    min, max = xs[0], xs[0]
    for _, x := range xs {
        if x < min { min = x }
        if x > max { max = x }
    }
    return   // "naked" return: returns min, max
}
Use sparingly

Named returns are great for documentation on short functions. Naked returns in long functions hurt readability.

Variadic functions

func sum(nums ...int) int {
    total := 0
    for _, n := range nums { total += n }
    return total
}
sum(1, 2, 3)
xs := []int{4, 5}
sum(xs...)   // spread a slice

Functions as values and closures

func counter() func() int {
    n := 0
    return func() int {   // closes over n
        n++
        return n
    }
}

next := counter()
fmt.Println(next(), next(), next())  // 1 2 3

apply := func(f func(int) int, v int) int { return f(v) }
fmt.Println(apply(func(x int) int { return x * x }, 5)) // 25

init and main

func main() is the program entry point of package main. Each file may also have func init(), which runs automatically before main. Use it sparingly.

Pass by value

Everything in Go is passed by value: the callee gets a copy. Slices, maps and channels are small headers that point at shared data, so modifications through them are visible to the caller. For other types, pass a pointer (next section) if the function needs to change the original.
