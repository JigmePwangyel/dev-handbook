Variables, Constants and Basic Types

Go is statically typed, but the compiler infers most types for you. This lesson covers how to declare values, the built-in types, and Go's "zero value" rule that removes a whole class of uninitialized-variable bugs.

Declaring variables

var name string = "Ada"   // explicit
var age = 36              // type inferred (int)
var count int             // zero value: 0

city := "Lisbon"          // short declaration, only inside functions
x, y := 1, 2              // multiple at once

:= declares and assigns; = only assigns to something that already exists. Unused local variables and unused imports are compile errors. That keeps code tidy.

Use int and float64 unless you have a reason not to.

Zero values

Every variable is initialized. Without an explicit value it gets its type's zero value:

var i int      // 0
var f float64  // 0
var b bool     // false
var s string   // "" (empty string)
var p *int     // nil
var sl []int   // nil slice
Design for useful zero values

Idiomatic Go types work without a constructor when possible. A zero sync.Mutex or bytes.Buffer is ready to use.

No implicit conversions

var a int = 10
var b float64 = float64(a) * 1.5   // explicit conversion required
// var c float64 = a               // compile error

Constants and iota

const Pi = 3.14159
const (
    Small = iota   // 0
    Medium         // 1
    Large          // 2
)

type Weekday int
const (
    Sunday Weekday = iota
    Monday
    Tuesday
)

iota is a counter that resets in each const block. It is Go's idiom for enums.

Strings and runes

s := "héllo"
fmt.Println(len(s))          // 6 (bytes, not characters!)
for i, r := range s {        // range iterates runes
    fmt.Println(i, string(r))
}

Printing

fmt.Println("a", 1)             // a 1
fmt.Printf("%s is %d\n", "Ada", 36)
fmt.Printf("%v %+v %T\n", p, p, p) // value, with field names, type
s := fmt.Sprintf("%.2f", 3.14159) // format into a string
