Why Go, and Setting Up

Go (often "Golang") is a compiled, statically typed language created at Google in 2009 by Robert Griesemer, Rob Pike and Ken Thompson. It was designed to make building fast, reliable network software boring in the best way: small language, fast compiles, one obvious way to do most things.

What Go is good at

  • Backend services and APIs: a great standard library for HTTP, JSON, crypto and more.
  • Cloud and DevOps tooling: Docker, Kubernetes, Terraform, Prometheus and Caddy are all written in Go.
  • CLIs: compiles to a single static binary you can copy anywhere, with no runtime to install.
  • Concurrent programs: goroutines and channels are built into the language.

Install

Download the installer from go.dev/dl, or use a package manager:

brew install go          # macOS
sudo apt install golang  # Debian/Ubuntu (may be an older version)
go version               # verify, e.g. go version go1.24 darwin/arm64

Your first module

mkdir hello && cd hello
go mod init example.com/hello   # creates go.mod

Create main.go:

package main

import "fmt"

func main() {
    fmt.Println("Hello, Go!")
}
go run .      # compile and run in one step
go build      # produce a binary named after the module
./hello

The toolchain you get for free

CommandPurpose
go runCompile and run
go buildProduce a binary
go test ./...Run all tests
go fmt ./...Format code. There is one official style, so no formatting debates
go vet ./...Static checks for suspicious code
go mod tidyAdd missing and remove unused dependencies
Editor setup

Use VS Code with the official Go extension (or GoLand). It installs gopls, the language server, and runs gofmt on save.

Try it

  1. Install Go and run the hello program.
  2. Change the message, then break it on purpose (delete a quote) and read the compiler error.
  3. Run go build and check the binary size with ls -lh. Note that it is self-contained.
