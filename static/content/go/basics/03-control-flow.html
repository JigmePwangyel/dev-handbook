Control Flow

Go keeps control flow minimal: one loop keyword (for), if, switch, and defer. No parentheses around conditions, braces always required.

if

if x > 10 {
    fmt.Println("big")
} else if x > 5 {
    fmt.Println("medium")
} else {
    fmt.Println("small")
}

// init statement: variable scoped to the if/else chain
if n, err := strconv.Atoi(input); err != nil {
    fmt.Println("bad number:", err)
} else {
    fmt.Println("parsed", n)
}

for: the only loop

for i := 0; i < 5; i++ { }      // classic

for x < 100 { x *= 2 }          // like while

for { /* forever */ break }      // infinite, exit with break

nums := []int{10, 20, 30}
for i, v := range nums { fmt.Println(i, v) }
for i := range 3 { fmt.Println(i) }          // 0 1 2 (Go 1.22+)
for k, v := range map[string]int{"a": 1} { fmt.Println(k, v) }

break and continue work as expected; labels let you break out of nested loops:

outer:
for i := 0; i < 3; i++ {
    for j := 0; j < 3; j++ {
        if j == 2 { continue outer }
        if i == 2 { break outer }
    }
}

switch

No fallthrough by default, so no break needed:

switch day {
case "sat", "sun":
    fmt.Println("weekend")
case "fri":
    fmt.Println("almost")
default:
    fmt.Println("weekday")
}

// expressionless switch replaces if/else chains
switch {
case score >= 90: grade = "A"
case score >= 80: grade = "B"
default:           grade = "C"
}

// type switch (more in the interfaces lesson)
switch v := val.(type) {
case int:    fmt.Println("int", v)
case string: fmt.Println("string", v)
}

Use the fallthrough keyword only when you truly want the next case to run.

defer

defer schedules a call to run when the surrounding function returns, in last-in-first-out order. It is the idiom for cleanup:

f, err := os.Open("data.txt")
if err != nil { return err }
defer f.Close()      // runs no matter how we leave the function
// ... use f ...
Arguments are evaluated immediately

defer fmt.Println(i) captures the value of i at the time of the defer statement, not when it runs.
